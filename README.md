# Lab 21 — Capteurs embarqués Android

## 📌 Objectif du Lab

Ce laboratoire a pour objectif de développer une application Android capable d’exploiter les capteurs embarqués d’un smartphone Android.

L’application permet :

- d’afficher les capteurs disponibles ;
- de lire les données des capteurs en temps réel ;
- d’afficher un graphe dynamique ;
- d’utiliser l’accéléromètre, le gyroscope et le champ magnétique ;
- d’utiliser `SensorManager` et `SensorEventListener`.

---

# 🛠️ Technologies utilisées

- Java
- Android Studio
- Android SDK
- SensorManager API
- Fragments Android
- Custom View (`LineChartView`)

---
